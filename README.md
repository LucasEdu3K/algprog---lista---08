## 📌 Exercícios

### Exercício 1 — Triângulo de números repetidos
Imprime um triângulo onde cada linha `i` contém o número `i` repetido `i` vezes.

```
1
2 2
3 3 3
...
n n n ... n
```

> Utiliza uma função que recebe `n` inteiro e imprime até a n-ésima linha.

---

### Exercício 2 — Triângulo crescente
Imprime um triângulo onde cada linha `i` contém os números de `1` até `i`.

```
1
1 2
1 2 3
...
1 2 3 ... n
```

> Utiliza uma função que recebe `n` inteiro e imprime até a n-ésima linha.

---

### Exercício 3 — Soma de três argumentos
Programa com uma função que recebe **três argumentos** e retorna a soma deles.

---

### Exercício 4 — Sinal do número
Função que recebe um argumento e retorna:
- `'P'` — se o argumento for **positivo**
- `'N'` — se for **zero ou negativo**

---

### Exercício 5 — `somaImposto`
Função que recebe dois parâmetros:
- `taxaImposto` — percentual do imposto sobre vendas
- `custo` — custo do item antes do imposto

A função altera o valor de `custo` para incluir o imposto.

---

### Exercício 6 — Conversor de horário (24h → 12h)
Converte horários no formato 24h para o formato 12h com indicação A.M./P.M.

**Exemplo:** `14:25` → `2:25 P.M.`

Requisitos:
- Entrada em dois inteiros (hora e minuto)
- Pelo menos **duas funções**: uma para conversão e uma para saída
- `'A'` para A.M. e `'P'` para P.M.
- Loop para repetir o cálculo com novos valores
